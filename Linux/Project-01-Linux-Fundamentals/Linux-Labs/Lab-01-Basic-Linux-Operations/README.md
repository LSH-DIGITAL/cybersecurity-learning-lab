Linux Lab 01: Basic Linux Operations

Overview

This lab documents my first hands-on experience working with a Linux command-line environment.

The purpose of this lab was to understand the fundamentals of Linux system navigation, file management, searching, permissions, and basic system information gathering.

Linux is an essential skill in cybersecurity because many servers, security tools, and penetration testing environments are built on Linux.

---

Lab Environment

Platform:

- Ubuntu Linux Playground (Killercoda)

Operating System:

- Ubuntu Linux

---

Objectives

The main objectives of this lab were:

- Understand basic Linux terminal usage
- Navigate through the Linux file system
- Create and manage files and directories
- Search for files and information
- Understand basic file permissions
- Gather system information

---

Tasks Completed

1. Linux Navigation

Commands Practiced:

pwd
ls
ls -la
cd

Purpose:

These commands were used to:

- Identify the current working directory
- View files and directories
- Display hidden files
- Navigate between directories

Cybersecurity Relevance:

Security professionals need to confidently navigate Linux systems during security assessments, investigations, and administration tasks.

---

2. File and Directory Management

Commands Practiced:

mkdir
touch
cp
mv
rm

Purpose:

These commands were used to:

- Create new directories
- Create files
- Copy files
- Rename or move files
- Remove unnecessary files

Example Tasks Completed:

- Created a cybersecurity practice directory
- Created text files for testing
- Copied and renamed files
- Removed unwanted files

Cybersecurity Relevance:

File management skills are required when handling scripts, reports, logs, and security tools.

---

3. Searching and File Analysis

Commands Practiced:

find
grep
cat

Purpose:

These commands were used to:

- Locate files
- Search for specific information inside files
- Read file contents

Cybersecurity Relevance:

Security analysts use these commands for:

- Log analysis
- Searching suspicious activity
- Investigating files
- Finding important information inside systems

---

4. Linux File Permissions

Commands Practiced:

ls -l
chmod

Purpose:

These commands were used to understand:

- File ownership
- Read permissions
- Write permissions
- Execute permissions

Cybersecurity Relevance:

Incorrect permissions can create security vulnerabilities.

Understanding permissions helps security professionals:

- Protect sensitive files
- Reduce unauthorized access
- Identify security weaknesses

---

5. System Information Gathering

Commands Practiced:

whoami
uname -a
ip address
hostname

Purpose:

These commands were used to collect information about:

- Current user
- Operating system
- Network configuration
- System identity

Cybersecurity Relevance:

Information gathering is an important step in:

- Security assessments
- Incident response
- System administration
