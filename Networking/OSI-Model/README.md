# OSI Model

## Overview

The OSI (Open Systems Interconnection) model explains how data communication happens between devices in a network.

It divides networking into 7 layers.

---

# The 7 OSI Layers

## Layer 7 - Application

Purpose:
Provides network services directly to users.

Examples:
- HTTP
- HTTPS
- DNS
- SSH

Cybersecurity:
- Web attacks
- SQL Injection
- XSS
- Authentication attacks


## Layer 6 - Presentation

Purpose:
Handles data formatting, encryption, and compression.

Examples:
- Encryption
- Data encoding

Cybersecurity:
- Weak encryption
- TLS vulnerabilities


## Layer 5 - Session

Purpose:
Creates and manages communication sessions.

Cybersecurity:
- Session hijacking
- Cookie attacks


## Layer 4 - Transport

Purpose:
Controls end-to-end communication.

Protocols:
- TCP
- UDP

Cybersecurity:
- Port scanning
- SYN flood attacks


## Layer 3 - Network

Purpose:
Handles IP addresses and routing.

Examples:
- IPv4
- Routers

Cybersecurity:
- IP spoofing
- Routing attacks


## Layer 2 - Data Link

Purpose:
Handles local network communication.

Examples:
- MAC addresses
- Switches

Cybersecurity:
- ARP spoofing
- MAC attacks


## Layer 1 - Physical

Purpose:
Transmits raw bits using signals.

Examples:
- Cables
- Radio signals

Cybersecurity:
- Hardware attacks
- Physical access attacks
