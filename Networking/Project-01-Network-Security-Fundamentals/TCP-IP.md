# TCP/IP Model

## Overview

The TCP/IP model is the foundation of modern internet communication. It describes how data is transmitted between devices across networks.

Unlike the OSI model, which has seven layers, the TCP/IP model uses four main layers.

## The 4 Layers of TCP/IP

## 1. Network Access Layer

Responsible for communication between devices on the same network.

Examples:
- Ethernet
- Wi-Fi
- MAC addresses

Security concerns:
- MAC spoofing
- Unauthorized network access
- ARP attacks

---

## 2. Internet Layer

Responsible for logical addressing and routing data between networks.

Protocols:
- IP (Internet Protocol)
- ICMP

Security concerns:
- IP spoofing
- Routing attacks
- ICMP abuse

---

## 3. Transport Layer

Responsible for reliable communication between applications.

Protocols:
- TCP
- UDP

Security concerns:
- Port scanning
- Denial-of-Service attacks
- Connection hijacking

---

## 4. Application Layer

Provides services directly to applications and users.

Protocols:
- HTTP/HTTPS
- DNS
- FTP
- SSH

Security concerns:
- Web vulnerabilities
- Data exposure
- Phishing attacks

---

# TCP/IP and Cybersecurity

Understanding the TCP/IP model helps cybersecurity professionals:

- Analyze network traffic
- Identify attack locations
- Configure security controls
- Troubleshoot network issues
- Use security tools effectively

## Tools Related to TCP/IP Analysis

- Wireshark
- Nmap
- Cisco Packet Tracer

## Summary

The TCP/IP model is essential for understanding how devices communicate and how network attacks occur.
